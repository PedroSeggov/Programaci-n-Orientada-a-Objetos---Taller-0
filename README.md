# Programación Orientada a Objetos - Taller 01

Este repositorio contiene la solución al Taller 01 de la asignatura de **Programación Orientada a Objetos (POO)** de la **Universidad Católica del Norte**.

## 📋 Descripción del Proyecto
El sistema consiste en una aplicación de consola desarrollada en **Java** que gestiona datos de usuarios y realiza análisis de métricas de procrastinación, aplicando conceptos fundamentales de POO y manejo de archivos.
